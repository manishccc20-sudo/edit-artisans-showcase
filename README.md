# Manish: Cinematic Editor

Create a premium portfolio website for a professional video editor named Manish.

The website should feel cinematic, modern, minimal, creative and high-end. Do NOT make it look like a generic corporate portfolio.

Design:

- Dark black/charcoal background

- White typography

- Subtle gray tones

- Large cinematic visuals

- Smooth animations and transitions

- Modern editorial/fashion-inspired layout

- Lots of whitespace

- Bold typography

- Rounded corners used subtly

- Premium visual hierarchy

- Fully responsive for desktop, tablet and mobile

Hero section:

- Full-screen cinematic hero

- Large headline:

  "MANISH"

  "VIDEO EDITOR"

- Small subtitle:

  "Turning footage into stories that feel."

- CTA buttons:

  "VIEW MY WORK"

  "LET'S WORK TOGETHER"

- Add a large showreel video area/background

- Add subtle scroll animation

Navigation:

- Mobile hamburger menu

Showreel section:

Technical requirements:

- Use React

- Use Tailwind CSS

- Make it fully responsive

- Add smooth scrolling

- Add tasteful Framer Motion animations

- Optimize images and videos

- Lazy load project videos

- Make all buttons functional

- Use accessible semantic HTML

- Make the site fast and SEO friendly

- Add Open Graph metadata

- Use placeholder images/videos where actual media is not provided

- Make it easy for me to replace every placeholder video, thumbnail, profile photo and social link later.

Important:

The final website should look like a professional creative agency/editor portfolio, similar in quality to an award-winning modern portfolio website.

Avoid excessive animations, gradients, neon colors, or clutter.

Focus on cinematic visuals, typography and storytelling.
